terrella

An interactive globe for the web. Highlight countries and regions, place markers, choose how it looks.

A terrella is a small model of the Earth. William Gilbert built one in 1600, magnetised it, and moved a compass over its surface to argue that the planet itself was a magnet. Every globe on this page is running live, not a picture of one.

Usage

The whole API

Two renderers, one interface. Swapping the import is the entire change, because both drive the same style painters. 

// 2D canvas, 7 KB with d3 external
import { createGlobe } from "terrella";

const globe = createGlobe(el, {
  world,
  style: "dots",
  regions: [
    { id: "sea", countries: [608, 360, 704] },
  ],
  markers: [
    { name: "Manila", coords: [121, 14.6] },
  ],
});

globe.focus("sea");
// the same globe on a sphere
import { createGlobe } from "terrella/three";

const globe = await createGlobe(el, {
  world,
  regions,
  markers,
  arcs: [{ from: [3.4, 6.5], to: [-46.6, -23.5] }],
});

// WebGPU where available, WebGL2 elsewhere
globe.usingWebGL;
