A small model of the Earth.

terrella is an interactive globe for the web. Highlight countries, colour them by number, place markers, draw arcs, pick a style. One API, three outputs: a 20 KB canvas, a WebGPU sphere, and SVG from a server.

$ npm install terrella
  • MIT
  • TypeScript
  • React · web component · SSR
  • scroll to drive the globe · hover a country
01

Highlight countries.

Group countries into a region and give it a colour. Name them the way you know them: "PH", "PHL" or 608 all work, and countriesIn("Africa") names a whole continent. Hover any country on the globe for its name. 

regions: [{
  id: "sea",
  countries: ["PH", "ID", "VN", "MY", "SG"],
  highlight: ["PH"],
}]
02

Place markers.

A marker is a name and a coordinate. Give it a timezone and hovering shows the local time. Markers hide as they pass the horizon, which an orthographic projection will not do for you. 

globe.setMarkers([
  { name: "Manila", coords: [121, 14.6],
    timezone: "Asia/Manila" },
]);
03

Colour by number.

A value per country becomes a choropleth. The ramp runs from land to highlight unless you give one; a function works for thresholds. 

globe.setValues({
  NG: 213, ET: 120, EG: 109, CD: 99,
  TZ: 63, ZA: 60, KE: 54,
});
04

Aim the camera.

focus glides to the centroid of a region's countries and holds there, so you never work out an angle by hand. flyTo faces any coordinate; tour visits a list of them. 

await globe.focus("africa");
await globe.flyTo([3.4, 6.5]);
05

Name things.

Labels sit at each country's centroid, hide past the horizon, fade toward the limb, and carry a halo so they read on any palette. 

globe.setLabels({
  countries: "regions",
  markers: true,
});
06

Change the style.

Seven built in: solid, dots, wireframe, hatched, pixel, ascii and stipple. A style is one paint function, so writing your own takes a few lines, and it works in every renderer. 

globe.setStyle("dots");
07

Or the projection.

The same globe, unrolled. Regions, markers and styles come along. 

globe.setProjection("naturalEarth");
08

Any palette.

Nine colours, any subset. Or set them as CSS custom properties and let the globe follow the page; theme: "auto" follows the system. 

globe.setPalette({
  ocean: "#1c1c19",
  land: "#3d3c37",
  highlight: "#ff6a33",
});
globe.setPalette({
  ocean: "#eeece5",
  land: "#d3d0c5",
  highlight: "#d9481b",
});
09

Night falls.

The night side follows the real sun and moves once a minute. This is where it is right now. 

globe.setTerminator(true);
10

Or a real sphere.

Import from terrella/three and the same options render on a sphere, with WebGPU where it exists and WebGL2 where it does not. Drag to orbit. 

// the same options, a different import
import { createGlobe } from "terrella/three";

const globe = await createGlobe(el, {
  world, regions, markers, arcs,
});

Use it the way you build.

The same options everywhere: a function, a React component, or an element in plain HTML. Server-rendered SVG for the first paint. 

import { createGlobe, countriesIn } from "terrella";
import { world } from "terrella/world";

const globe = createGlobe(el, {
  world,
  regions: [{ id: "africa", countries: countriesIn("Africa") }],
  markers: [{ name: "Lagos", coords: [3.4, 6.5] }],
  values: { NG: 213, ET: 120 },
  labels: true,
  theme: "auto",
  onCountryClick: (c) => console.log(c.name),
});

await globe.focus("africa");
import { Globe } from "terrella/react";
import { world } from "terrella/world";

<Globe
  world={world}
  regions={regions}
  markers={markers}
  globeStyle="dots"
  focus="sea"
  onCountryClick={(c) => setCountry(c)}

focus(id, { duration })
Glide to a region and hold. Pass null to release it.
flyTo(coords)
Face a coordinate, or an explicit longitude and tilt.
tour(stops, { dwell, loop })
Visit stops in turn. Returns a handle to stop it.
setStyle(style)
One of seven names, or your own painter.
setValues(values, scale)
A number per country, painted through a ramp or a function.
setPalette(colors)
Merge new colours in. Any subset of the nine.
setTheme(theme)
Light, dark, or follow the system. Re-reads --terrella-* properties.
setLabels(options)
Names on countries and markers, with occlusion.
setTerminator(options)
The night side, for now or for a given moment.
setMarkers(list)
Replace the markers in place.
setProjection(name)
Orthographic, natural earth or equirectangular.
toSVG()
What is on screen, as a string.
onCountryHover, onCountryClick
The country under the pointer, with its name and codes.
arrow keys
Turn the globe. A hidden list names every region and marker for screen readers.
